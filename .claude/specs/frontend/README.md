# Frontend Specs

This directory is the source of truth for product-facing behavior, user flows, UI rules, and client responsibilities for the Couples Connection app.

## File Index

1. `01-introduction-and-onboarding.md` - Product vision, app entry, authentication UX, and partner pairing flows.
2. `02-couple-profile-and-relationship-management.md` - Personalization, relationship settings, and break or block controls.
3. `03-emotional-status-system.md` - Shared status, mood, and energy interactions.
4. `04-stories.md` - Photo and video story creation plus delivery behavior.
5. `05-direct-messaging-and-calls.md` - Messaging, voice notes, and video call product rules.
6. `06-retention-and-engagement.md` - Notifications, streaks, games, and memories from the user perspective.
7. `07-widgets-ios-android.md` - Widget customization, layouts, and quick actions.
8. `08-subscription-model-and-premium-access.md` - Pricing tiers and premium entitlements in the client experience.

## Notes

- These files describe what users see and do in the app.
- Backend service behavior, data ownership, realtime delivery, storage, and operational rules now live in `../backend/`.
- The original consolidated product spec remains in `../couple.md`.
