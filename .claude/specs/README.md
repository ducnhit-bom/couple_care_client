# Couples Connection App Specs

This directory now separates product-facing frontend specifications from backend service specifications.

## Source Of Truth

- `frontend/` - client experience, UI behavior, and user-facing product flows.
- `backend/` - service architecture, APIs, realtime systems, storage, and operational rules.

## Directory Index

- `frontend/README.md` - index for all frontend specs.
- `backend/README.md` - index for all backend specs.
- `couple.md` - original consolidated product spec preserved for historical context.

## Migration Note

- The previous flat spec layout has been reorganized into `frontend/` and `backend/`.
- Any tooling or manual references to the old file paths should be updated to the new directories.
